# Seguridad, lenguaje y calidad — contrato vinculante
## Redacción
Toda pantalla ha de responder a «¿qué puedo hacer ahora?». Tono tranquilo y directo, sin culpabilizar, sin infantilizar ni garantizar resultados. Priorizar llamada humana cuando hay peligro inmediato. Nunca usar «todo está bien», «estás a salvo» o «no hay incidencias» sin evidencia.

## Clasificación de estados
- Ubicación ACTUAL: coordenadas y precisión que comunica el sistema, fecha/hora.
- Ubicación ANTERIOR: no llamarla actual ni utilizarla para hacer afirmaciones de cercanía no verificadas.
- Ubicación MANUAL: referencia escrita o punto seleccionado; diferenciar anotación de geocodificación confirmada.
- RECURSO VERIFICADO: fuente, URL/documento original, fecha extracción, horarios/servicios y última comprobación.
- RECURSO SIN VERIFICAR: nunca indicarlo como abierto, próximo, accesible o de urgencias.
- ALERTA: zona de aplicación, inicio, fin, fuente y hora de recepción; jamás «sin alertas» por fallo de conexión.

## Reglas críticas
1. 112 disponible siempre desde la pantalla principal. El teléfono aún necesita red telefónica.
2. Si no hay red, explicar brevemente que no puede cursarse la llamada y dar pasos de ayuda razonables, sin animar a rutas peligrosas.
3. Las fichas sanitarias y psicológicas no diagnostican ni reemplazan profesionales; contenido sensible validado.
4. Todas las acciones se prueban con modo avión, servicios de localización desactivados, permiso denegado, GPS débil, datos caducados y pérdida de conexión.
5. Toda guía muestra procedencia y fecha; la adaptación para menores se revisa.
6. Nunca publicar datos personales, rutas, coordenadas históricas o ubicaciones de menores.
7. No publicar capturas simuladas como si fueran datos reales.
8. Los servicios físicos se validan con directorios oficiales y coordenadas contrastadas.
9. El nombre Artemis y el icono requieren comprobación de marcas antes de distribución.

## Puertas de calidad
- PR con checklist funcional, privacidad, copy, accesibilidad y pruebas offline.
- Revisión de dos perfiles: técnica + seguridad/contenido antes de publicar guías críticas.
- Evidencia de prueba en móvil físico; no marcar terminado por una maqueta.
- Versión pública solo tras auditar recursos, teléfonos, zonas de riesgo, permisos y políticas de menores.
